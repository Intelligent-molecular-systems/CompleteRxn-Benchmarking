# Main benchmark prediction files

This folder holds the saved predictions behind the paper results. The files are too large for Git and are hosted in the [reproduction repository](https://huggingface.co/datasets/Intelligent-molecular-systems/completeRXN-reproduction) on Hugging Face. Download them and place them at the paths below.

```text
results/main/predictions/
  rb/{random,group,extreme_ood}/<repetition>/
  crb/{random,group,extreme_ood}/<repetition>/
  synrbl/benchmark_final_results_noRI_complete.csv
  synrbl/eval_all_splits_noRI_complete/full_results.csv
```

RB and CRB each have one folder per repetition: `random_seed42_rep0` through `random_seed46_rep4`, `group_rep0` through `group_rep4`, and `extreme_ood_rep0` through `extreme_ood_rep4`. To rescore, each folder needs `beamSize5_nBest5.txt`, `beamSize5_nBest5.txt_log_probs` and `top1_predictions_with_stats.txt`. Other files in these folders, such as `full_results.csv` and summaries, are generated by scoring and don't need to be downloaded.

For SynRBL, rescoring needs only `eval_all_splits_noRI_complete/full_results.csv` (`noRI` = without reagent identification, see [Terms](../../../README.md#terms)). The raw prediction CSV above is the SynRBL output it was built from.

The appendix analyses need these additional files:

| Analysis | Required saved asset |
|---|---|
| SynRBL with vs. without reagent identification | `results/SynRBL/eval_all_splits_CanonicalReaction/full_results.csv` |
| SynRXN | `results/main/predictions/crb/synrxn/beamSize5_nBest5.txt` (included in Git) |
| Uncurated CRB | `results/main/predictions/crb/uncurated/loaded_balanced.csv` |
| Uncurated diagnostics | `results/main/predictions/crb/uncurated/merged/beamSize5_nBest5_all.txt` |
| Uncurated SynRBL | `results/SynRBL/uspto_uncurated_CanonicalReaction_results/*_results.csv` |
| Historical (v1) agreement comparison | `results/archive/metric_v1/additional/uncurated_consensus_uids/{confident_agree_uids,agree_not_confident_uids}.csv` |

The uncurated failure analysis also reads the master dataset and a similarity cache; their default paths are shown by its `--help` option.

Check that all files are in place with:

```bash
find results/main/predictions/{rb,crb}/{random,group,extreme_ood} -name beamSize5_nBest5.txt | wc -l
test -f results/main/predictions/synrbl/eval_all_splits_noRI_complete/full_results.csv
```

The first command should print `30` (2 models × 3 splits × 5 repetitions). The paper scores computed from these predictions are in `results/main/scores/`. Historical v1 scores of the same predictions are in `results/archive/metric_v1/main/scores/`.
